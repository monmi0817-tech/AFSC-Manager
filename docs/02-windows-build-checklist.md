# Windows 빌드 및 MVP 1 확인 목록

## 빌드

1. Windows 10/11에 .NET 8 SDK를 설치한다.
2. 프로젝트 폴더에서 PowerShell을 연다.
3. 다음을 실행한다.

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\build-windows.ps1
```

완료되면 `artifacts\win-x64\AfterSchoolManager.exe`가 생성된다.

## 최초 실행 확인

- 앱 실행 시 흰 화면이 아니라 작업공간 선택 화면과 5개 탭이 표시되는지 확인
- 새 작업공간을 생성한 후 상단에 학년도·작업공간·기간이 표시되는지 확인
- `%LOCALAPPDATA%\AfterSchoolIntegratedManager\data\afterschool.db`가 생성되는지 확인
- 실행이 중단되면 `%LOCALAPPDATA%\AfterSchoolIntegratedManager\app.log`에 오류가 기록되는지 확인

## MVP 1 업무 흐름 확인

1. 학생 2명을 직접 추가한다.
2. 학생명단 Excel 양식을 내려받아 학생 2명을 추가로 가져온다.
3. 학생 한 명에게 방과후 이용권, 같은 학생에게 자유수강권을 각각 추가한다.
4. 학생정보 표의 지원유형이 `방과후 이용권 + 자유수강권`으로 표시되는지 확인한다.
5. 부서와 네 가지 비용을 입력한다.
6. 학생을 부서에 수강 등록한다.
7. 수강생 명단에 전교생 전체가 아니라 등록한 학생만 표시되는지 확인한다.
8. 동일 학생·동일 부서를 다시 등록했을 때 중복 오류가 표시되는지 확인한다.
9. 부서 기본금액을 수정해도 이미 등록된 수강생의 금액은 바뀌지 않는지 확인한다.

## Excel 검증 확인

- 학생명단에 없는 수강생은 오류 행으로 표시되는지 확인
- 이름이 학년·반·번호와 일치하지 않으면 오류가 표시되는지 확인
- 존재하지 않는 부서는 오류가 표시되는지 확인
- 정상 행은 저장되고 오류 행은 요약에 남는지 확인

## 현재 MVP의 의도된 제한

- 학교별 실제 품의 템플릿 적용은 후속 템플릿 어댑터 범위다.
- 업데이트 확인은 개인정보 보호를 위해 자동 백그라운드 실행이 아니라 사용자가 버튼을 누르는 방식이다.
- 실제 설치 EXE 생성에는 Windows의 .NET 8 SDK와 Inno Setup 6이 필요하다.

MVP 1의 `선택 삭제(입력 오류)`는 잘못 가져온 수강 원본을 정리하는 기능이다. 실제 중도취소 업무에는 사용하지 않고 MVP 3의 상태 변경 기능을 사용한다.

## MVP 2 정산 확인

1. 왼쪽 메뉴의 `학년도 지원금 설정`에서 방과후 이용권과 자유수강권 기본 한도를 저장한다.
2. 중복 대상자의 적용순서를 선택한다.
3. 필요한 경우 학생별 지원 한도와 변경 사유를 저장한다.
4. 같은 학년도의 가장 오래된 작업공간을 선택한다.
5. `정산 데이터 생성`에서 정산을 실행한다.
6. 다음 작업공간도 날짜순으로 정산한다.
7. `수익자`, `방과후 이용권`, `자유수강권` 화면의 금액을 확인한다.
8. 앞선 작업공간의 수강이나 지원금 설정을 변경했을 때 최신상태 경고가 표시되는지 확인한다.
9. 오래된 선행 작업공간을 다시 정산하지 않은 상태에서는 다음 작업공간 정산이 차단되는지 확인한다.

정산 불변식은 개별 비용마다 다음과 같다.

```text
실제 적용금액 = 일반 수익자 + 방과후 이용권 + 방과후 이용권 초과금 + 자유수강권
```

## MVP 3 변경 관리 확인

1. 부서정보의 수강료를 수정한다.
2. 수강생 명단에서 `부서금액 다시 불러오기`를 실행한다.
3. 수기 조정이 없는 수강은 기본금액과 실제금액이 함께 변경되는지 확인한다.
4. 이미 수기로 조정한 수강은 기본금액만 변경되고 실제금액은 유지되는지 확인한다.
5. 수강을 선택해 항목별 실제금액과 변경사유를 저장한다.
6. 취소일과 사유를 입력하고 수강취소를 실행한다.
7. 취소된 행이 삭제되지 않고 `수강취소` 상태로 남는지 확인한다.
8. 정산 데이터가 오래된 상태로 표시되는지 확인한다.
9. 정산 재생성 후 변경된 실제금액이 반영되는지 확인한다.
10. 변경이력과 학생 상세정보 화면에서 기록을 확인한다.

## MVP 4 품의자료 확인

1. 현재 작업공간의 정산 데이터를 최신 상태로 생성한다.
2. `품의 양식 받기`에서 강사료를 선택한다.
3. 부서별 일반 수익자·이용권 초과금·이용권 지원금·자유수강권·합계를 확인한다.
4. 2026학년도 이용권 대상 학년이 3학년이면 `수익자(1,2,4,5,6학년)`, `3학년 초과금`, `3학년 지원금`으로 표시되는지 확인한다.
5. 수용비·교재비·재료비 선택 시 해당 비용만 집계되는지 확인한다.
6. 교재·재료비 통합 선택 시 교재비와 재료비의 합계가 표시되는지 확인한다.
7. Excel 저장 후 각 부서 행의 합계와 마지막 전체 합계를 확인한다.
8. 수강 금액을 변경한 뒤 정산을 재생성하지 않으면 품의 저장이 차단되는지 확인한다.

## MVP 5 백업·설치·업데이트 확인

1. `기본 폴더에 백업`을 실행하고 `.afbackup` 파일이 생성되는지 확인한다.
2. 테스트 학생 또는 수강 데이터를 추가한 뒤 이전 백업을 복원한다.
3. 복원 전 데이터가 `%LOCALAPPDATA%\AfterSchoolIntegratedManager\recovery`에 자동백업되는지 확인한다.
4. 복원된 작업공간·학생·수강·정산·변경이력을 확인한다.
5. 손상된 파일이나 일반 ZIP 파일을 복원할 때 현재 DB가 유지되는지 확인한다.
6. Inno Setup 6 설치 후 `build-installer.ps1`을 실행한다.
7. 설치·업데이트·제거 후 `%LOCALAPPDATA%\AfterSchoolIntegratedManager\data\afterschool.db`가 유지되는지 확인한다.
8. GitHub 저장소를 `owner/repository` 형식으로 저장하고 업데이트 확인을 실행한다.
9. 새 Release 설치파일 다운로드 시 진행률이 표시되고 다운로드 후 설치가 실행되는지 확인한다.
